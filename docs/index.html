About this archive

The Jogo Disk was a bonus CD bundled with Champak, India's beloved fortnightly children's magazine (Delhi Press), produced by Digerati from the mid-2000s to the early 2010s. Each disc carried shareware and embeddable Flash games that could run offline, plus extras like wallpapers and paint tools.

This project preserves every volume that survives publicly — 98 discs, 38,489 files (~10.2 GB raw) — re-hosted as GitHub Release assets so the games are downloadable forever, no account required.

How the games play

Most games are .swf files. Run them in Ruffle (free, in-browser Flash emulator). Some discs include .exe extras (Click and Paint, Magic Blackboard, wallpapers) that run on Windows or via Wine. .dcr Shockwave titles have no maintained emulator.

Integrity

Every download is SHA-1 verified against archive.org metadata before it is re-published. Per-volume hashes, sizes and source URLs live in catalog/source_manifest.csv and catalog/vol_*.json in the GitHub repo.
